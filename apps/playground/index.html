地球飞线

沿测地线抬升一条弧线，让光点在两地之间循环移动。

使用示例

@cesiumlab/effects

import { createFlowingArc }
  from '@cesiumlab/effects';

const arc = createFlowingArc(viewer, {
  from: [103.82, 1.35],
  to: [139.69, 35.68],
  height: 430_000,
  duration: 4,
});

// 离开场景时
arc.destroy();

传入已有的 Viewer。调用 destroy() 可移除飞线及光点。
