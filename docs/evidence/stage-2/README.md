## 动画假设与实际周期

参考是静态 AI 概念图，以下为设计假设：

- 金色光点沿三维弧线由各节点流向上海；`routeSpeed=1` 时飞行时间约 **3–5s**，按路径长度调整；
- 每条飞线有连续 `PolylineGlow` 拖尾，默认约占路径 **18%**；尾部 `taperPower` 渐隐、头部保持亮度，叠加金白色光点与 billboard；
- 蓝色节点持续 **3 圈**错位波纹：约 **0.8s** 生成一圈、单圈 **2.4s**，任意时刻约 2–3 圈同时可见；不同节点初始相位不同；
- 金色中心持续 **3 圈**环境波纹：约 **1.07s** 生成一圈、单圈 **3.2s**，无抵达时也持续存在；
- 飞线抵达时额外触发 **2 圈**约 **1.3s** 的强脉冲与中心增亮；强脉冲初期扩张快、随后减速/变宽/消散；激活期间新抵达合并/节流；
- 中心环境波纹与强脉冲叠加，但环境波纹不因强脉冲中断或重置；
- 动画可暂停/继续；暂停时飞线、节点环、中心波纹与光束呼吸一起冻结；
- 节点光束呼吸周期约 7s，幅度很小；不同节点有不同高度/亮度/相位；
- 节点光柱默认与倾斜侧视角下的三维锚定、层次和顶部消散已检查；

## 视觉参考与实际结果的前三处差异

1. **地表细节**：参考有更暖、更清晰的地形/城市灯光；本实现使用 4096×2048 夜景纹理，细节更少、色调更蓝。
2. **边界表现**：参考是饱和青色霓虹边界与更丰富的内部线网；本实现用 Natural Earth 数据，边界受 Bloom 影响偏白，省界较细，且自然地理数据与概念图轮廓不同。
3. **金色弧线与拖尾**：参考约 8 条更粗的金色弧线和更强的中心光晕；本实现 7 条较细弧线、单条 taper 拖尾，Bloom 更强但体积层次略弱；地球弧面位置也略低（主截图顶部仍保留约 10% 星空）。

## Node Energy Beam 技术路线

- 每个节点约 90 个径向辉光 billboard，沿高度分 3 层：亮白核心 36、青蓝内晕 30、柔和外晕 24；
- 越靠顶部尺寸越小、透明度按 `(1-t)^1.35` 衰减至 0，避免硬截断；
- `scaleByDistance` 在近景放大、远景缩小，近似透视；底部额外柔光与节点核心衔接；
- 呼吸约 7s 周期、幅度很小，各节点高度/亮度/相位略有差异；
- 局限：billboard 始终朝向相机，是“相机朝向的体积近似”，不是真正的体积光/Shader 光线步进；近景可看到层叠粒子感。默认视角与旋转侧视角已检查。

## 实现摘要

- `main.ts`：Viewer、夜景纹理、大气、可选地形、Bloom、相机、控制面板、清理；
- `network.ts`：Natural Earth 边界/省界、7 节点、7 条三维弧线与 taper 拖尾、上海中心、节点 3 圈持续波纹 + 中心环境波纹/抵达强脉冲、节点全息光束堆叠、CallbackProperty 动画；
- `geo.ts`：本地 GeoJSON 解析；
- `textures.ts`：运行时生成辉光 sprite；
- `controls.ts` / `controls.css`：参数面板（颜色/透明度/亮度/拖尾/速度/弧高/光束参数/暂停）。

## 未验证 / 限制

- Firefox / Safari / 移动端未验证；仅 Edge/Chromium headless。
- 没有真实录屏；用 `t=0/2/5/10s` 时间序列代替，符合任务允许的证据方式。
- 夜景纹理近看会糊；省界/边界不是测绘级精度；节点光柱底部为近似高度，极端视角可能看出悬浮/穿地。
- 拖尾是 `PolylineGlow` taper 近似，不是自定义逐顶点流体/体积拖尾；近看仍有线条边界。
- 节点光束由约 90 个相机朝向 billboard 沿高度堆叠，是体积近似；近景可见层叠粒子感，不是 Shader 体积光/光线步进。
- 光点为屏幕空间 point/billboard，未做景深、运动模糊或真实体积光。
- ion 端点超时或不可用时回退椭球地形；地形起伏与遮挡会与参考不同。
- 未做像素级差异、SSIM 或跨设备性能/FPS 结论。
- **未获得用户视觉批准**；不得进入 Stage 3 通用化或 npm 发布。
